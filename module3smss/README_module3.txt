Файл для модуля 3: 05_module3_order_cost_query.sql

Что делает:
- считает стоимость строки заказа по материалам;
- считает итоговую полную стоимость заказа;
- использует активную спецификацию;
- использует последнюю актуальную цену материала.

Как запускать:
1. Убедись, что база ProductionDB уже создана.
2. Убедись, что таблицы из модуля 2 уже созданы.
3. Запусти файл целиком в SSMS.
4. Для расчета конкретного заказа измени значение:
   @OrderNumber = N'ORD-001'

Если в базе пока нет данных по:
- Product
- Material
- MaterialPrice
- Specification
- SpecificationMaterial
- CustomerOrder
- CustomerOrderItem

то запрос выполнится, но может вернуть пустой результат.
